# Task 005 테스트 가이드 — 참여자 모바일 UI/UX

Task 005에서 구현한 기능(보기 시점 토글, 이벤트 목록 역할 탭, 이벤트 상세 참여자 뷰, 초대 링크 참여 페이지)을 직접 브라우저에서 확인하기 위한 가이드입니다.

## 0. 사전 준비

1. 개발 서버 실행: `npm run dev`
2. 기본 URL: `http://localhost:3000`
3. `http://localhost:3000/auth/login`에서 기존 계정으로 로그인합니다. `(main)` 하위 라우트(`/events`, `/profile` 등)는 `proxy.ts`가 인증된 세션을 요구합니다.

> **주의**: 로그인 후 앱에 표시되는 "나"는 실제 로그인 계정과 무관하게 항상 더미 데이터의 `profile-1`(김태호)로 고정되어 있습니다(`lib/dummy-data.ts`). 아래 모든 시나리오는 이 `profile-1` 기준입니다.

---

## 1. 보기 시점 토글 — `/profile`

`http://localhost:3000/profile`로 이동해 "주최자 시점"/"참여자 시점" 버튼을 클릭합니다.

| 상태                 | 하단 내비게이션 "새 이벤트" | 우하단 FAB(＋) 버튼 |
| -------------------- | --------------------------- | ------------------- |
| 주최자 시점 (기본값) | 표시됨                      | 표시됨              |
| 참여자 시점          | 숨겨짐                      | 숨겨짐              |

"내 이벤트"/"프로필" 항목은 두 시점 모두에서 항상 유지되어야 합니다.

---

## 2. 이벤트 목록 역할 탭 — `/events`

`http://localhost:3000/events`에서 역할 탭(전체 / 내가 만든 이벤트 / 내가 참여한 이벤트)을 클릭합니다. 상태 필터(전체/예정/진행중/종료)와 조합해서도 확인해 보세요.

| 탭                 | 표시되어야 할 이벤트                                                                        |
| ------------------ | ------------------------------------------------------------------------------------------- |
| 전체               | 10개 전부                                                                                   |
| 내가 만든 이벤트   | 2026 신년 모임, 주말 등산 모임                                                              |
| 내가 참여한 이벤트 | 사이드 프로젝트 킥오프, 동네 러닝 크루 정기모임, 저녁 보드게임 모임, 생일 파티, 여름 워크숍 |

---

## 3. 이벤트 상세 — 호스트 뷰 vs 참여자 뷰

이벤트 카드를 클릭하거나 아래 URL로 직접 이동해 비교합니다.

**호스트 뷰** (수정/삭제/공유 버튼 노출):

- `http://localhost:3000/events/event-1`
- `http://localhost:3000/events/event-8`

**참여자 뷰** (수정/삭제/공유 버튼 숨김, 참여자 목록만 노출):

- `http://localhost:3000/events/event-2`
- `http://localhost:3000/events/event-4`
- `http://localhost:3000/events/event-6`
- `http://localhost:3000/events/event-7`
- `http://localhost:3000/events/event-10`

**제3자 이벤트** (참여도 하지 않아 "전체" 탭에서만 보이는 경우, 상세 페이지는 참여자 뷰와 동일하게 읽기 전용):

- `http://localhost:3000/events/event-3`
- `http://localhost:3000/events/event-5`
- `http://localhost:3000/events/event-9`

---

## 4. 초대 링크 참여 페이지 — 로그인 불필요

`/join/[invite_code]`는 `proxy.ts`의 인증 예외 경로라 로그인 없이도 접근할 수 있습니다.

| 이벤트                  | URL                                   |
| ----------------------- | ------------------------------------- |
| 2026 신년 모임          | `http://localhost:3000/join/gthr01ab` |
| 사이드 프로젝트 킥오프  | `http://localhost:3000/join/gthr02cd` |
| 독서 모임 3월           | `http://localhost:3000/join/gthr03ef` |
| 동네 러닝 크루 정기모임 | `http://localhost:3000/join/gthr04gh` |
| 아침 요가 클래스        | `http://localhost:3000/join/gthr05ij` |
| 저녁 보드게임 모임      | `http://localhost:3000/join/gthr06kl` |
| 생일 파티               | `http://localhost:3000/join/gthr07mn` |
| 주말 등산 모임          | `http://localhost:3000/join/gthr08op` |
| 봄맞이 피크닉           | `http://localhost:3000/join/gthr09qr` |
| 여름 워크숍             | `http://localhost:3000/join/gthr10st` |

- **정상 케이스**: 위 URL 중 아무거나 방문 → 커버 이미지/제목/설명/장소/일시/참여자 수 미리보기가 표시됨 → "참여하기" 버튼 클릭 → `"{이벤트명}" 이벤트에 참여했습니다` 토스트 표시
- **실패 케이스**: `http://localhost:3000/join/no-such-code` 방문 → Next.js 404 페이지("This page could not be found.") 표시
